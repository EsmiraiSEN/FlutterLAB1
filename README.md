## Ответы на вопросы
1. **Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?**
   В Dart типы данных проверяются на этапе компиляции, а в Python — динамически во время выполнения кода. Главное преимущество статической типизации заключается в том, что компилятор находит ошибки несовместимости типов заранее, не допуская падения программы в рантайме.

2. **Что означает String? Чем отличается от String?**
   `String` — это гарантированно не-null тип, переменная обязательно должна содержать строковое значение. `String?` — это nullable-тип (благодаря механизму Sound Null Safety), который сообщает компилятору, что переменная помимо строки может принимать значение `null`.

3. **Зачем в Dart final, если в Python можно просто договориться не менять переменную?**
   Договоренности между разработчиками легко нарушить по ошибке. Ключевое слово `final` защищает переменную на уровне компилятора — при попытке перезаписать её код просто не скомпилируется, предотвращая потенциальные баги.

4. **Чем именованный параметр {required String name} отличается от позиционного? Приведите пример вызова.**
   Именованный параметр передается по имени внутри фигурных скобок `{}` при вызове функции, его порядок не важен. Модификатор `required` делает его обязательным для передачи. Позиционный параметр зависит строго от его позиции в объявлении.
   *Пример вызова именованного параметра:* `printStats(name: 'Артём Иванов', grades: [5, 4, 5]);`
